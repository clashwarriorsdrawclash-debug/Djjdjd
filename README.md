# Archive des livres

Bibliothèque de PDF : recherche (titre, auteur, **texte intégral**) et lecture, hors ligne. Téléphone et PC.
Les PDF restent sur ton appareil (IndexedDB), rien n'est envoyé.

## Publier sur GitHub Pages
1. Crée un dépôt GitHub et envoie-y ces 5 fichiers : `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
2. Dépôt → **Settings → Pages** → Source : *Deploy from a branch* → `main` / `/ (root)` → Save.
3. Ouvre `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.
4. Téléphone : menu du navigateur → *Installer l'application*. PC (Chrome/Edge) : icône d'installation dans la barre d'adresse.

Les mises à jour du dépôt arrivent au 2e lancement de l'appli.

## Commandes
| | PC | Téléphone |
|---|---|---|
| Naviguer | flèches | toucher |
| Ouvrir / Retour | Entrée / Échap | toucher / bouton retour |
| Ajouter (X) / Rechercher (Y) | `x` / `/` ou Ctrl+K | boutons du bas |
| Chercher dans le livre | Ctrl+F | loupe |
| Zoom | `+` `-` ou Ctrl+molette | pincer, double tap |
| Mode nuit / Sommaire | `n` / `t` | boutons du lecteur |

Une manette (A, B, X, Y + croix) fonctionne aussi, comme sur Recalbox.
